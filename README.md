### Fineract Consumer-Facing

[![Apache Fineract Consumer-Facing](https://img.shields.io/badge/Apache-Fineract_Consumer--Facing-D22128?style=flat-square&logo=apache&logoColor=white)](https://github.com/apache/fineract-consumer-facing)

Contributing to the consumer-facing application and its backend-for-frontend (BFF), with an emphasis on reliable integrations, architectural boundaries, automated testing, and efficient builds.

**Selected contributions**
- **End-to-end testing:** Playwright journeys covering registration, multi-factor authentication, accounts, transfers, loans, and authorization against a real application stack.
- **Architecture enforcement:** ArchUnit rules for CQRS, layering, module boundaries, and naming conventions, with a shrink-only baseline for existing violations.
- **Adapter architecture:** Isolating generated API clients, UI overlays, internationalization, and browser storage behind maintainable interfaces.
- **Static analysis:** Integrating Error Prone, SpotBugs, Modernizer, and frontend linting rules.
- **CI and performance:** Improving native-image builds, reducing runtime memory requirements, and strengthening automated test workflows.

**Selected pull requests**
- [Full-stack Playwright journeys with MFA](https://github.com/apache/fineract-consumer-facing/pull/193)
- [Enforce BFF architecture conventions with ArchUnit](https://github.com/apache/fineract-consumer-facing/pull/189)
- [Extend adapter boundaries to i18n and Web Storage](https://github.com/apache/fineract-consumer-facing/pull/183)
- [Add static analysis and frontend lint rules](https://github.com/apache/fineract-consumer-facing/pull/171)
- [Reduce BFF memory requirements](https://github.com/apache/fineract-consumer-facing/pull/164)
- [Build the BFF as a GraalVM native image](https://github.com/apache/fineract-consumer-facing/pull/165)

Explore the [Fineract Consumer-Facing repository](https://github.com/apache/fineract-consumer-facing) and [all my pull requests](https://github.com/apache/fineract-consumer-facing/pulls?q=is%3Apr+author%3AAman-Mittal).
